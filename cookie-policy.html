Cookie Policy

Last updated:

This Cookie Policy explains how Flooring Match uses cookies, local storage, and related technologies when you visit the website.

Current position

The current version uses local storage only to remember your privacy-choice acknowledgement. No Flooring Match analytics, advertising, audience measurement, or cross-site behavioral tracking is configured.

1. Scope of this policy

This policy covers small pieces of data stored on or accessed from your browser by the Flooring Match website, as well as relevant external resources loaded to display the site. It should be read together with the Privacy Policy.

2. What cookies and similar technologies are

A cookie is a small text file that a website places on a browser or device. Similar technologies include local storage, session storage, pixels, software development kits, and other mechanisms that save information or access information already stored on a device.

These technologies may be used for essential operation, preferences, security, measurement, personalization, or advertising. The current Flooring Match implementation uses only the limited preference storage described below.

3. Technologies currently used

Browser storage used by Flooring Match

flooring-match-cookie-choice First-party local storage Remembers that you selected the necessary-only privacy setting so the notice does not appear on every visit. Until you clear browser storage or the site changes or removes the value.

Local storage is not automatically sent with every web request in the way a traditional cookie may be. The site's JavaScript reads this value in your browser to determine whether to display the privacy notice.

4. Essential preference storage

The preference value is treated as necessary for remembering the privacy control you selected. It is not used to infer interests, build a profile, measure marketing performance, or follow you across unrelated websites.

If browser storage is unavailable, blocked, or cleared, the site can still be browsed, but the privacy notice may be shown again because the previous choice cannot be recalled.

5. Server and security information

The website host, network, and security systems may process ordinary request information—such as IP address, browser information, requested URL, timestamps, and response or security logs—to deliver pages, diagnose errors, and prevent abuse. This server-side handling is not the same as placing a browser cookie, but it is described in the Privacy Policy because it may involve personal information.

6. External fonts and resources

The current stylesheets request web fonts through Google Fonts. When a browser loads an external font stylesheet or font file, it connects to Google's servers and may send standard connection information such as an IP address, browser details, and the requested resource. Flooring Match does not use that connection for its own advertising or behavioral profiling.

If fonts are self-hosted or the external resource changes, this policy should be updated to reflect the production configuration.

7. Analytics and advertising

No analytics platform, advertising pixel, remarketing tag, profiling tool, or cross-site tracking integration is active in the current implementation. Selecting “Use necessary only” therefore records a preference but does not disable an analytics tool, because none is currently configured.

Before any non-essential technology is added, the operator should assess the applicable notice and consent requirements, update this policy, and provide appropriate controls.

8. How to manage your choice

You can reopen from this page or the footer. You can also clear the Flooring Match local-storage value through your browser's privacy, site-data, or developer settings.

Browser controls differ by product and version. Clearing all site data may also remove preferences saved by other websites. Blocking JavaScript or storage may affect parts of the site's interface.

9. Do Not Track and Global Privacy Control

Because the current site does not engage in cross-site behavioral advertising or sell project-request information through tracking technologies, it does not apply a separate behavioral response to Do Not Track or Global Privacy Control signals. If the site's practices change, this section and the applicable controls should be reviewed.

10. Retention

The local-storage preference remains on the same browser and device until you clear site data or the website changes or removes the value. Server or security logs, where maintained by production infrastructure, should be retained only as long as reasonably necessary for operation, security, troubleshooting, and applicable legal requirements.

11. Future technologies and policy changes

This policy will be updated if the website begins using additional cookies, local-storage values, analytics, embedded media, chat tools, maps, advertising, conversion measurement, or other integrations. Material changes should be reflected in the privacy controls before non-essential technologies are activated where prior consent is required.

The “Last updated” date identifies the current version.

12. Contact

Questions about browser storage or privacy choices may be submitted through the website contact route. A dedicated privacy contact and the operator's legal details must be added before live production submissions are accepted.

Production note: This policy reflects the current codebase. Recheck it whenever third-party scripts, analytics, marketing tools, embedded content, or hosting infrastructure changes.
